# セキュリティ診断スキル（Claude Code・Codex）

会社のセキュリティが今どこまで守れているか、次に何をすればいいかが、1 枚のレポートでわかります。質問に選んで答え、PC の設定を読み取ると、事故の場面ごと（ウイルス感染、PC の紛失、退職者のアカウントなど）にまとめたレポートがブラウザで開きます。IT の専門家でなくても使えます。

Claude Code と Codex のどちらでも使えます。

診断は目安です。安全を保証するものではありません。

## 入れ方

1. このページの右にある「Releases」から、いちばん新しい版の `security-checkup-v〇.〇.〇.zip` をダウンロードし、展開します。
2. できた `security-checkup` フォルダを、使っている道具のスキル置き場にコピーします。

| 道具 | Mac | Windows |
|---|---|---|
| Claude Code | `~/.claude/skills/security-checkup` | `%USERPROFILE%\.claude\skills\security-checkup` |
| Codex | `~/.agents/skills/security-checkup` | `%USERPROFILE%\.agents\skills\security-checkup` |

`skills` フォルダがなければ作ってください。コピーしたら、Claude Code か Codex を開き直します。

新しい版に入れ替えるときは、古い `security-checkup` フォルダを消してから（または `skills` フォルダの外へ移してから）コピーします。上からコピーすると、古い版にだけあったファイルが残ります。これまでの診断結果は別の場所にあるので、消えません。

## 使い方

Claude Code か Codex で「セキュリティ診断をしたい」と話しかけます（Codex では `$security-checkup` と書いて呼び出すこともできます）。最初に、立場（経営者、総務・情シス担当、一般社員）とパソコンの詳しさを聞かれます。答えに合わせて、質問の言葉と進め方が変わります。

- 経営者・担当者: 会社への質問に、選択肢から答えます。わからないものは「わからない」を選んで構いません。それも結果の一部になります。最初に「設定は誰がしていますか」と聞かれます。業者や別の人に任せていると答えると、バックアップの世代や VPN の機器の状態のような詳しい質問は聞かれず、レポートの「業者・担当者に聞くこと」に、そのまま業者に送れる文で載ります。
- 一般社員: 自分の PC だけを調べます。数分で終わります（Mac の「システムレポート」の読み取りは、少し長くかかることがあります）。

診断の結果はレポートに出ます。チャットには、全体のレベルや場面ごとの状態は出ません。レポートを開いて確かめてください。

### 社員の PC をまとめて診断するとき

1. 担当者が、社員に案内文を送ります。ひな型は `security-checkup/docs/employee-notice.md` にあります。
2. 社員は、自分の PC で「PC の診断をしたい」と Claude Code か Codex に話しかけ、できた結果ファイルを担当者に送ります。
3. 担当者は、受け取ったファイルを「書類（Windows では「ドキュメント」）」の中の「セキュリティ診断」フォルダにある「社員PC結果」に入れます。
4. そのあとで会社の診断をすると、「社員PC結果」フォルダのファイルが自動でレポートに集まり、PC の場面に反映されます。Claude や Codex はこのファイルの中身を読みません（レポートを作る実行スクリプトが 1 件ずつ取り込みます）。壊れたファイルや書き換えられたファイルは、レポートに「読めなかった結果ファイル N 件」と出て、ほかの結果には影響しません。
5. 会社の PC の台数より確認できた PC が少ないうちは、PC の場面（PC の紛失、ウイルス対策、OS の更新）は、確認できた分が良くても「わからない」と出ます。「あと何台が未確認か」もカードに出ます。

## 診断のあとで（無料個別相談）

レポートのいちばん下から、AIでええやんの無料個別相談を申し込めます。診断の結果をもとに、何から直すかを担当者と一緒に決められます。

申し込みページ（aideeyan.com）で送信を押したときに、そのページで入力した内容だけが送られます。診断の結果や PC の設定は送られません。

## 読むもの・読まないもの

読むのは PC の設定だけです。たとえば次のものです。

- ウイルス対策ソフトの有無と、更新の新しさ
- ディスクの暗号化、ファイアウォール、画面ロックの設定
- OS の更新の状況とサポート期限
- 管理者権限で使っているか、外から接続する仕組みがあるか
- ブラウザや VPN ソフトの版、クラウドの同期ソフトの有無

次のものは読みません。

- 個人のファイル、写真、書類の中身
- ブラウザの閲覧履歴
- メールの中身

設定は変えません。診断中にネットワークへ出ることもありません。

## 結果の保存先

「書類」フォルダ（Windows では「ドキュメント」）の中に、「セキュリティ診断」フォルダができます。Windows で OneDrive がドキュメントをバックアップしている場合、このフォルダは OneDrive の中にあることがあります。

- セキュリティ診断
  - 日付ごとのフォルダ: 会社の診断レポート（`report.html` など）が入ります。
  - 社員PC結果: 社員 PC の結果ファイルを入れる場所です。

日付フォルダの `pcs.js` は、「社員PC結果」の中身をレポートに取り込んだものです。`pcs.html`（PC ごとの結果）は担当者だけが見るものです。PC の名前や役割ごとの状態が載っているので、フォルダごと社員に渡さないでください。

## 許可の確認が出たとき

Claude Code や Codex が、`run.ps1`（Windows）や `run.sh`（Mac）の実行、「書類」フォルダへの書き込み、レポートをブラウザで開く処理について確認を出すことがあります。これはこのスキルに入っている、設定を読むだけのチェックです。許可して大丈夫です。許可は診断の途中だけ有効で、メッセージを送り直すと、もう一度確認が出ることがあります。そのときも許可して大丈夫です。

Mac では、macOS が「書類フォルダなどへのアクセスを許可しますか」と聞くことがあります。許可しなくても診断は進みますが、その項目はレポートに「わからない」と出ます。

## 読んだ内容の扱い

診断で読んだ内容は、使っている道具と同じ扱いで送られます。Claude Code なら Anthropic（Claude）に、Codex なら OpenAI に送られます。会社で使うなら、法人向けのプランでの利用をおすすめします。

## 診断の限界

- 目安であり、安全を保証しません。「問題なし」と出ても、事故が起きないとは言えません。
- Claude Code も Codex も使っていない社員の PC は調べられません。台数に数え、レポートでは「未確認」と出ます。全台が確認できるまで、PC の場面は「守れている」とは出ません。
- 経営者だけが答えたときは、バックアップの保存先、退職者アカウントの件数、メールの 2 段階認証の対象などの詳しい質問が聞かれません。その場面は、担当者に確かめるまで「守れている」とは出ません。
- Mac で他社のウイルス対策ソフトを使っていると、定義ファイル（ウイルスを見分けるデータ）の新しさが取れず、「わからない」と出ます。
- 管理者権限がないと読めない項目は「わからない」になります。

## 基準表の日付と更新

OS のサポート期限、ブラウザの最低バージョンなどの判定は、`security-checkup/report/baseline.js` の表をもとにしています。この表の日付は 2026-10-24 です。レポートの上にも「基準表：○○ 時点」と出ます。時間がたつと、現実とずれていきます。

更新するには、次のどちらかを選びます。

- `baseline.js` の値を直接書き換える。日付（`asOf`）、OS の期限（`osSupport`）、ブラウザの最低バージョン（`browserMinMajor`）が対象です。
- 配布元から新しい版のスキルを入手し、`security-checkup` フォルダを入れ替える。

半年に一度ほどは、更新が必要か確かめてください。
