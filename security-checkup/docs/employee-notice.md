# 社員への案内文のひな型

担当者がメールやチャットに貼って使えます。〔　〕の部分を書き換えてください。

---

件名: 〔　〕月〔　〕日までに PC のセキュリティ確認をお願いします

みなさん、お疲れさまです。会社のセキュリティの現状を知るため、各自の PC の設定を確認してもらいます。個人の評価には使いません。

■ やること
自分の PC で Claude Code を開き、「PC の診断をしたい」と話しかけてください。数分で終わります（Mac は少し長くかかることがあります）。
途中で「PC の名前か部署・役割」を聞かれたら、「営業 1」のように答えてください。氏名は書かないでください。

■ 読むもの
PC の設定だけです。ウイルス対策ソフト、ディスクの暗号化、OS の更新、画面ロックなどを見ます。設定は変えません。

■ 読まないもの
個人のファイル、ブラウザの閲覧履歴、メールの中身は読みません。

■ 読んだ内容の送り先
読んだ内容は、Claude Code を使うときと同じように、Claude（Anthropic）に送られます。どう扱われるかは、会社が契約しているプランで決まります。

■ 結果を見る人
会社全体のレポートには、個人名も PC ごとの結果も出ません。PC ごとの結果を見るのは、担当者の〔　〕だけです。

■ 許可の確認が出たとき
Claude Code が確認を出したら、許可して大丈夫です。設定を読むだけのチェックです。Mac で書類フォルダへのアクセスを聞かれたときも、許可して大丈夫です。許可しなくても進められますが、その項目は「わからない」と記録されます。

■ 終わったら
診断が終わると、「PC診断_（名前）_（日付）.json」というファイルができます。「書類」（Windows では「ドキュメント」）の中の「セキュリティ診断」にある「社員PC結果」フォルダに入っています。このファイルを、〔メール／チャットなど〕で〔担当者名〕に送ってください。

わからないことがあれば、〔担当者名〕まで聞いてください。
